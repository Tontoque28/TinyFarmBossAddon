# Información del Proyecto: T28's Universal Veinminer

## ModID: universalveinminer
## Nombre del Mod: T28's Universal Veinminer
## Versión Actual: 1.0.2
## Autor: Tontoque28
## Summary: A simple, lightweight, and highly configurable universal Veinminer mod for Minecraft Forge 1.20.1!
## Descripción Breve: Un mod que implementa la funcionalidad de Veinminer de forma universal para Minecraft Forge 1.20.1. Permite minar múltiples bloques del mismo tipo con una sola acción (agachado), respeta encantamientos (Fortuna, Toque de Seda), daño de herramienta y agotamiento. Configurable ingame con comandos y tecla dedicada.
