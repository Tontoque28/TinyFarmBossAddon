## Objetivo
Crear un sistema de supervivencia dinámico impulsado por IA que monitoree la progresión del jugador, calcule un Nivel de Amenaza en tiempo real y active dinámicamente eventos hostiles adaptativos.

## Descripción Técnica
Mod que implementa un sistema de Director de IA para monitorear el estado del jugador y el entorno, calculando un Nivel de Amenaza dinámico (0-100). Este nivel de amenaza influye en la activación de eventos hostiles adaptativos como emboscadas, presión de mobs y aparición de élites, sin modificar las reglas de spawn globales de Minecraft. El sistema está diseñado para ser modular, escalable y respetuoso con el rendimiento y la compatibilidad.
