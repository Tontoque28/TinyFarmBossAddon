## Descripción Técnica
Mod que modifica drásticamente el comportamiento de los Creepers para hacerlos extremadamente peligrosos, ahora con selección de dificultad dinámica.
- **Insta Boom:** Explotan instantáneamente al contacto (radio 4.0 bloques).
- **No Fuse:** Sin tiempo de mecha.
- **No Stop:** No se detienen para hincharse.
- **Velocidad:** Aumentada significativamente (hasta x2.25).
- **Variantes:**
  - Charged Creepers naturales (35% noche).
  - Alpha Creepers (Glowing, 40HP, x3-x4 explosión).
- **Compatibilidad:** Intercepta explosiones de otros mods para forzar "Insta Boom" sin fuego.
- **Configuración:** Comando `/creeperdifficulty` para ajustar dificultad en tiempo real.
