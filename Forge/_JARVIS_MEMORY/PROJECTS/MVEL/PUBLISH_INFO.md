# Información de Publicación: MVEL

## Title
More Vanilla Enchantments Levels

## Summary
Increases the maximum levels of vanilla enchantments.

## Description
**Unofficial Mod**

This mod allows vanilla enchantments to have higher maximum levels than default.
Perfect for modpacks that require stronger equipment or RPG-style progression.

### Features
- Increases max levels for standard enchantments.
- Configurable (Planned).
