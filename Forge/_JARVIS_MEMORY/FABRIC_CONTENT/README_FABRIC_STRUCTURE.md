# PROTOCOLO DE AISLAMIENTO: ENTORNO FABRIC

====================================================
FUNCIÓN DE ESTE DIRECTORIO
====================================================
Este directorio `FABRIC_CONTENT` sirve como contenedor principal para todo el desarrollo relacionado EXCLUSIVAMENTE con el modloader Fabric.

====================================================
REGLAS APLICABLES (REFERENCIA USER_OVERRIDE_RULES)
====================================================
1. Aislamiento estricto: Todo el trabajo, simulaciones, y documentación de Fabric ocurrirá dentro de este entorno.
2. Nomenclatura compilada obligatoria: [NombreDelMod]-[VersiónDelMod]-Fabric-[VersiónDeMinecraft].

Cualquier proyecto nuevo creado aquí debe mantener la misma estructura organizada (PROJECT_INFO, CHANGELOG_INTERNAL, etc.) que se utiliza globalmente, pero alojada dentro de `FABRIC_CONTENT/PROJECTS/`.
