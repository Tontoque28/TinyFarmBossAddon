# Tiny Farm Boss Remastered (Fabric 1.20.1) - Versión 1.1.2

## Descripción General

Tiny Farm Boss Remastered es un addon esencial para Tiny Mob Farm, diseñado para expandir las capacidades de captura y farmeo a entidades que, de otro modo, serían imposibles de granjear en Minecraft 1.20.1. Este mod, ahora completamente portado a Fabric, permite a los jugadores capturar bosses icónicos como el Wither, el Ender Dragon y el Warden utilizando el Lasso, integrándolos de forma segura en sus granjas de mobs.

## Características Principales

*   **Captura de Bosses:** Permite la captura del Wither, Ender Dragon y Warden con el Lasso de Tiny Mob Farm.
*   **Tablas de Botín Personalizadas y Equilibradas:** Los bosses capturados ahora proporcionan drops específicos y ajustados para una experiencia de farmeo gratificante y equilibrada:
    *   **Wither:** Dropea Nether Star y una cantidad moderada de Arena de Almas.
    *   **Ender Dragon:** Dropea Huevo de Dragón, una cantidad aumentada de Aliento de Dragón, Cabeza de Dragón con probabilidad ajustada, y una probabilidad muy rara de Elytra.
    *   **Warden:** Dropea Catalizador de Sculk, Fragmentos de Eco, Bloques de Sculk, Shriekers de Sculk y Venas de Sculk, con cantidades ajustadas para un farmeo equilibrado.
*   **Compatibilidad Avanzada (Anti-Crash):** Incorpora un sistema robusto para la captura y generación de botín segura de mobs con lógicas complejas o problemáticas, como los dragones de Ice and Fire, piratas/bárbaros de MineColonies o Slimes vanilla. Esto previene crashes de servidor y asegura un funcionamiento estable.
*   **Entity Crash Handler:** Un sistema integral que monitorea y gestiona el procesamiento de entidades para evitar fallos, registrando detalles en `tmf_entity_crashes` y aplicando fallbacks seguros dinámicos.
*   **Soporte Multipartes:** Permite interactuar y capturar entidades complejas haciendo clic en sus partes secundarias (ej. alas de dragón).

## Dependencias

*   Minecraft 1.20.1
*   Fabric Loader
*   Fabric API
*   Tiny Mob Farm (Requerido)
