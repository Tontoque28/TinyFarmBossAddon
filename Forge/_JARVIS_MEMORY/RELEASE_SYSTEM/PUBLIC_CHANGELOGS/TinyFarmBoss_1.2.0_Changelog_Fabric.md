v1.2.0 (Fabric):
- **Universal Loot Safeguard:** Ensured that bosses drop their key items (Nether Star, Dragon Egg, etc.) even if other mods attempt to overwrite their loot tables, doing so in a non-destructive manner.
- **Improved "Ice and Fire" Compatibility:** Enhanced the compatibility layer to prevent crashes when using custom forks or community editions.
- **New Mod Support:** Added native compatibility to capture and farm bosses from **L_Ender's Cataclysm** and **Terramity**.
- **User Configuration File:** You can now customize the addon without needing an update!
  - Add custom mobs from any mod to the capture whitelist.
  - Block problematic mobs or entire namespaces (e.g., `minecolonies:*`) using the blacklist feature to prevent server crashes.
