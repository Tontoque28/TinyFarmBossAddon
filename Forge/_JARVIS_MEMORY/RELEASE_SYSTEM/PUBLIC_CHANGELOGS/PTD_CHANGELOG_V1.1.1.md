# Progressive Time Difficulty (PTD) - Changelog v1.1.1

## Version 1.1.1 (Hardcore Balance Update)
**Date:** 23/02/2026
**Minecraft:** 1.20.1
**Loader:** Forge

### ⚠️ Major Changes
**Hardcore Mode Rebalance:**
- **Damage Buff Increased:** The damage multiplier in Hardcore Mode has been increased from **x1.5** to **x2.5**.
    - *Reason:* To provide a genuine threat for players with high-tier armor in large modpacks.
- **Knockback Resistance:** Slightly increased scaling for knockback resistance in Hardcore Mode (0.1 -> 0.15).

### 🛠️ Fixes & Improvements
- **Dynamic Difficulty:** The mod now respects your world difficulty (Easy/Normal/Hard).
- **Modded Boss Support:** Mobs tagged as `forge:bosses` automatically receive boss bonuses.
- **Iron Golem Rebalance:** Iron Golems now receive an extra x2 difficulty multiplier.
- **Persistence:** Hardcore Mode and Dev Mode settings are now saved and persist after server restarts.
- **Fixes:** Fixed bugs with difficulty change messages and Iron Golem buffs.
