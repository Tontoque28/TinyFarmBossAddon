# More Vanilla Enchantments Levels - Changelog v1.0.0

## Version 1.0.0 (Initial Release)
**Minecraft:** 1.20.1
**Loader:** Forge

### Features
- Initial release.
- Increases the maximum levels of most vanilla enchantments.
- Uses a robust Mixin strategy to ensure compatibility with other mods.

### Fixes
- Fixed a critical crash that occurred when playing in large modpacks due to an incorrect Mixin injection.
- Corrected Mixin warnings related to fishing enchantment class names.
