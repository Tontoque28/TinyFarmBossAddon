# Progressive Time Difficulty (PTD) - Changelog v1.1.3

## Version 1.1.3 (Experience & QoL Update)
**Date:** 23/02/2026
**Minecraft:** 1.20.1
**Loader:** Forge

### ⚠️ Major Changes
**Scalable Experience:**
- Mobs now drop more experience as they become stronger, rewarding players for tackling tougher enemies.
- **Formula:** `BaseXP * (1.0 + (DifficultyFactor * 1.2))`.
- **Example:** A mob that drops 5 XP on Day 1 might drop 16 XP on Day 100.

### 🛠️ Fixes & Improvements
- **Dev Stick:** The debug stick now shows the base and final XP drop of a mob.
- **Environmental Damage:** Rebalanced environmental damage to be more aggressive in late-game.
- **Code Cleanup:** Removed unnecessary comments and improved code structure.
